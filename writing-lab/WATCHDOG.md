# 运行健康巡检（看门狗）

> 用途：机器可能随时断电、休眠，定时任务可能**根本没触发**，也可能**触发了但做到一半断掉**。
> 本文件是巡检的唯一真相源；每小时一次的巡检任务读它、更新它，异常才汇报，正常静默。
>
> 原则：**只读检查 + 记录 + 告知**。看门狗不写文章、不发文章、不发第二封邮件，避免它自己变成新的不稳定来源。
> 重活一律交回正常触发点（10:30 / 14:30 / 21:30 / 周一 20:00 / 周二 20:00）续做，那些入口都是幂等的。

## 一、检查项与判定标准

| # | 线 | 看什么 | 什么算异常 |
|---|---|---|---|
| A | 文章线 | `strands-in-action/PIPELINE_STATE.md` 的 `stage`、`last_run_date`、`ready_since`、顺延记录 | `stage` 停在 `outline/experiments/draft/review` 且 `last_run_date` 不是今天 → **疑似中途断电**；`ready_to_publish` 但 `ready_since` 已跨过一个发布窗口仍未发 → **待发积压**；顺延记录里有未销项 |
| B | 文章日报 | `writing-lab/engagement/reports/<今天>.html` | 22:00 之后仍缺当天 HTML → **日报未产出**（21:30 之前不算异常） |
| C | 周复盘 | `writing-lab/engagement/reports/` 本周 ISO 周是否有 `*-weekly.html` | 周一 20:30 后缺 → 观察；周二 20:30 后仍缺 → **本周复盘丢失**（补跑位也失手） |
| D | 渠道巡查 | `/Users/pinxiong/WorkBuddy/2026-10-29-07-53-05/redline-check-site/channel-echo-log.md` 是否有当天日期的一节 | 20:00 之后缺 → **巡查漏跑**（只记录，不代跑浏览器任务） |
| E | 评论 | `writing-lab/engagement/data/new-comments.md` | 非 `none` 且超过 2 小时仍无回复动作 → **待回复**（交 21:30 日报高亮） |
| F | 心跳 | 本文件的 `last_check_at` | 距上次检查 > 2 小时且这段时间是白天 → 说明机器长时间没开机，记为背景信息，不单独告警 |

## 二、动作分级

| 级别 | 情形 | 动作 |
|---|---|---|
| 🟢 全绿 | 无异常 | 只更新下面「最近一次检查」的 YAML，**不汇报、不发消息、不发邮件** |
| 🟡 黄 | 单次漏跑、日报晚出、巡查漏跑 | 记进「未完成清单」；交给下一个正常触发点续做。若当天 21:30 日报还没发，把它并入邮件顶部高亮区 |
| 🔴 红 | 影响发布：待发积压跨窗口、本周复盘丢失、文章线疑似中断且超过 24h 无推进、连续 2 天以上无任何任务心跳 | 立即在对话里汇报（说清楚哪项、多久没动、建议怎么办），并在当天日报邮件顶部置顶 |

**噪声控制**：同一条异常只在首次出现和状态变化时汇报，不要每小时重复同一句话。
